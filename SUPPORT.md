# Support

## How to Get Help

If you have a question, please check the following resources before opening an issue:

1. **[README](./README.md)** — covers installation, configuration, and usage
2. **[GitHub Issues](https://github.com/tareq-halaby/sql-powertools/issues)** — search existing issues before opening a new one

## Reporting Bugs

Found a bug? Please open a [GitHub Issue](https://github.com/tareq-halaby/sql-powertools/issues/new) and include:

- Your PHP and MySQL version
- Steps to reproduce
- Expected vs. actual behavior
- Relevant logs or error messages

## Security Issues

For security-related vulnerabilities, please **do not** open a public issue. Instead, refer to [SECURITY.md](./SECURITY.md) for responsible disclosure instructions.

## Contact

For general enquiries, you can reach the maintainer at **me@tareq.im**.
